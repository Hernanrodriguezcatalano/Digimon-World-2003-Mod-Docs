# Digimon World 2003 - Modding Project & Documentación

Bienvenido a la documentación técnica para el mod de *Digimon World 2003*. Este repositorio sirve como base de datos, registro de memoria y guía de descompilación enfocada en la modificación de NPCs, mapas y triggers de la historia.

## Objetivo del Proyecto
Modificar la ubicación de NPCs, alterar los triggers de eventos y agregar contenido a la historia original sin modificar los modelados visuales (archivos TIM/TMD), utilizando herramientas de descompilación y edición de RAM.
